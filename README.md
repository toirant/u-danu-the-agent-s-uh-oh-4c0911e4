One word an agent says when it has no idea what to do:

**recalculating**

It is the sound of a machine caught mid-task with no route left — not a
shrug, not an apology, just the agent stalling in its own voice while it
pretends it still knows where it is going.

## How it works

`main.ts` writes the single word to `/output/entry.txt` (creating `/output`
if needed), validating it first in code: exactly one word, 1–99 characters,
not whitespace-only — then reading the file back to confirm what landed on
disk is byte-for-byte the validated word.

Run it with:

```sh
node main.ts
```
